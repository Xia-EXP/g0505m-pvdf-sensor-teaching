## ui.py 集成（已完成，2026-10-19）

1. **页面切换**：顶栏加 `Segmented`：实时 / 实验 / 分析 / 标定。中央改为 `QStackedWidget`：
   第 0 页放现有内容（splitter + 回放条 + 操作栏），其余三页依次放
   `ExperimentPage(controller)`、`AnalysisPage()`、`CalibrationPage(controller)`。
   三个页面自带 50 ms 定时器，只读 controller 状态；实验页会调用 `controller.tare()`、
   `start_recording()`/`stop_recording()`、`record_event()`，这些都是现有公开方法。
2. **课堂 / 研究模式**：课堂模式隐藏“分析”“标定”两个切换按钮；研究模式全部显示。
3. **工整数据**：把“数值表”标签页换成 `DataGrid`（可保留原 25 行表作为“明细”标签页）。
   在 `render()` 里调用 `self.data_grid.set_data(values, peaks if frame else None, controller.scale_g, self.channel)`，
   并连接 `self.data_grid.selected` 到 `self.select_channel`。
4. **标定当量显示**：连接 `calibration_page.calibration_changed`，保存为 `self.calibration`。
   在“原始值 / 归零后”旁增加“标定当量”选项（`self.calibration is None` 或手不一致时禁用）。
   选中时 `values = self.calibration.apply(frame.values)`（用**原始值**换算，0 g 已是标定点，不再减零点），
   并调用 `data_grid.set_unit_note("单位：标定当量 g（仅对标定压头面积有效，不代表整手握力）")`。
   CSV 仍然只记录厂家原始值。
5. `ZONES` 现在定义在 `analysis.py`，ui.py 可改为 `from .analysis import ZONES`，避免两处定义漂移。

## 物理与安全边界（界面文字须保留）

- G0505M 是压阻阵列，读数为厂家估算 g；25 点合计不等于整手握力。
- 三维手的弯曲由受力推算，仅示意，不是实测关节角；软件不控制真实机械手。
- 标定只对所用压头面积、垂直居中加载有效；载荷不得超过登记量程 80%（软件会拒绝）。
  标定结果称“标定当量 g”，不换算为牛顿或帕斯卡。
- 示例数据下实验可以走流程，但结论会注明“不能作为实物测量证据”；标定页拒绝示例和回放数据。
