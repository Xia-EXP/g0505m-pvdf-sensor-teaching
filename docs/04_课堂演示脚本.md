# 课堂演示脚本

## 1. 课程目标

完成约 15 分钟演示后，学生应能说明：

1. 触摸如何让 PVDF 产生瞬态电信号；
2. 模拟电压如何被 ADC 转换成数字样本；
3. 为什么需要批帧、序号、时间戳和 CRC；
4. 原始波形如何变成动态强度和触摸事件；
5. 机器人为什么接收语义事件而不是直接接收全部 ADC 点；
6. 为什么 LDT0-028K 不能测量持续静态压力。

## 2. 课前检查

- 完成逐针接线和增益调整，确认 10 次重触无削顶。
- 打开上位机，连接 Pico 并完成轻/重触标定。
- 启动本机机器人模拟器，目标设为 `127.0.0.1:18080`。
- 先保持机器人输出禁用，确认急停或安全动作处于可控状态。
- 准备一根拔掉数据芯的充电线用于对比时，应明确贴标签，避免混用。

## 3. 15 分钟演示流程

### 0:00–1:30 观察传感器

展示 LDT0-028K、PVA103 和 Pico，沿数据流指出各自职责。

教师提问：“触摸传感器后，机器人最先得到的是压力数字吗？”

预期回答：不是。最先出现的是电荷/电压变化，经过放大、采样、算法后才得到相对动态强度和事件。

### 1:30–3:00 建立连接和基线

连接 Pico，指出 USB CDC 状态、2 kS/s、20 点/批和协议版本。保持装置静止 2 秒，让上位机完成基线。

强调界面若显示 115200，它只是串口兼容占位；USB CDC 实际传输不依赖传统 UART 波特率。

### 3:00–5:00 观察原始波形

依次做轻触、中触和重触，观察 ADC、输出电压、变化电压、包络和动态强度。

教师提问：“为什么波形有正有负，而且松手也可能出现一个脉冲？”

说明膜片弯曲方向和恢复方向相反，压电输出与形变变化有关。算法通常使用变化电压绝对值形成包络，但原始正负波形仍保留用于教学。

### 5:00–6:30 主动展示物理限制

按住触摸片约 2 秒不动。让学生看到开始时有峰值，随后回到基线，松手时又可能出现瞬态。

教师提问：“数据回到零是否说明手指已经离开？”

正确结论：不能这样判断。PVDF 对动态变化敏感，保持期间回落不代表压力消失；本装置不把它标成静态压力。

### 6:30–8:30 从样本到串口帧

打开帧信息，指出每 10 ms 把 20 个 12 位样本组成一帧。展示：

- `LS` 魔数用于从字节流中找回帧边界；
- 序号用于发现丢帧；
- 首样本时间戳用于恢复时间轴；
- CRC 用于拒绝损坏数据。

教师提问：“为什么不把每个 ADC 点都单独发一条 JSON？”

说明批帧降低传输和解析开销，而二进制格式能保留固定长度与校验。

### 8:30–11:00 从波形到机器人事件

启用机器人输出，完成一次触摸。沿界面的数据链状态依次指出：

`采样 → CRC 正确 → 包络超过阈值 → event_start → TCP JSON → 机器人 ACK → event_end`

同时展示机器人收到的 JSON。解释机器人通常只需要 20 Hz 的状态摘要和触摸开始/结束事件，不需要承担 2 kS/s 原始信号处理。

默认演示动作应是虚拟机器人变色、表情或低风险灯光反馈，不直接执行大幅运动。

### 11:00–12:30 展示确认与故障

停止机器人模拟器，再做一次触摸。上位机应继续采集波形，但机器人连接变为失败或未确认。重新启动模拟器后，不应补发断线期间的旧动作。

说明“传感器采到了”与“机器人确认执行了”是两个不同状态。

### 12:30–14:00 强度标定

分别做 5 次轻触和 5 次重触，说明程序使用中位数降低某一次操作过轻或过重的影响。完成后再做三档触摸，观察轻、中、重分类。

提醒百分比只在同一结构和同一标定下可比较。

### 14:00–15:00 总结

让学生复述完整链路：

`机械形变 → 电荷 → 模拟电压 → ADC 样本 → 带 CRC 的批帧 → 基线/包络 → 动态强度/事件 → TCP JSON → 机器人 ACK`

最后再次强调：本教具展示的是动态触摸数据如何进入机器人，不是静态电子秤。

## 4. 推荐课堂实验

### 实验 A：改变触摸位置

保持主观力度相近，分别触摸悬臂根部和自由端，比较峰值。用于说明机械结构会改变灵敏度。

实验结束后必须回到标记触摸点；不要用不同位置的数据混做强度标定。

### 实验 B：改变采样和显示角色

让学生观察 ADC 是 2 kS/s，而 UI 只需约 30 FPS、机器人遥测只需 20 Hz。讨论为什么“内部数据率”和“人的观看帧率”不相同。

### 实验 C：引入干扰

在安全距离内移动 USB 电源线或用手靠近未屏蔽输入线，观察基线噪声变化，再恢复正确布线。不得打开市电设备或让学生接触裸露市电。

## 5. 真实机器人演示约束

- 先在模拟器验证相同 JSON 和 ACK。
- 机器人侧只接受动作白名单，不接受任意关节角或脚本字符串。
- 触摸动作设置冷却时间和最大频率，防止振铃或连续拍打造成动作风暴。
- 断线后不重放旧事件；恢复连接后只处理新触摸。
- 运动前必须有人持有急停，清空机器人周围区域。
