# 机械装配与增益调整

## 1. 为什么机械结构属于测量系统的一部分

LDT0-028K 对膜片弯曲和变化速度敏感。同一根手指以同样感觉按下，如果触点位置、悬臂长度、覆盖材料或底部限位发生变化，输出峰值也会变化。因此标定完成后不能再随意移动膜片、改变胶带位置或拧紧夹具。

本教具的目标是可重复地演示动态触摸，而不是让学生直接捏裸膜片。推荐使用“柔性悬臂触摸片”结构。

## 2. 推荐机械结构

### 2.1 布局

把底板分成两区：

- 触摸区：位于底板一侧，学生只接触标记好的圆形区域；
- 电路区：PVA103 靠近传感器，Pico 靠近 USB 出口，两块板均用隔离柱固定。

传感器到 PVA103 的导线应短于 Pico 到电脑的 USB 线。不要为了让电路板看起来整齐而延长高阻抗的传感器输入线。

### 2.2 悬臂触摸片做法

1. 准备一片 0.2–0.5 mm PET 或薄 PP 片作为柔性舌片。
2. 只夹持舌片靠近底板的一端，另一端保持可上下弯曲。
3. 把 LDT0-028K 平贴在舌片下方，使主要感应区域位于会发生弯曲的位置。
4. 只在传感器非活动边缘和压接引线附近使用 Kapton 胶带；不要用厚双面胶覆盖整片膜。
5. 在舌片自由端两侧设置硬限位垫块，使标记触摸点从静止位置到限位面的最大下移量约为 1–2 mm；限位必须落在 PET/PP 舌片上，不能直接顶住 PVDF 膜。
6. 在硬限位的宽平接触面覆盖 0.3–0.5 mm 薄硅胶或泡棉作缓冲。硬件高度决定最大行程，软垫只降低撞击，不能用可被压扁的厚泡棉代替硬限位。
7. 在舌片上方标出直径约 15–20 mm 的触摸区，课堂中始终触摸同一位置。
8. 在传感器引线离开舌片的位置做一个松弛弯，再用扎带固定到基板，避免拉扯压接端子。

如果没有 PET 舌片，也可以把传感器的非活动端固定在底板边缘，让感应部分悬空，但仍必须设置约 1–2 mm 行程的硬限位和薄缓冲层，不能让学生把膜片折成尖角。

## 3. 不允许的装配方式

- 不要在 PVDF 膜片上打孔、订钉、热熔或直接焊接。
- 不要让螺钉或硬夹具压在活动感应区上。
- 不要把整片膜牢固粘死在厚硬板上；无法弯曲会显著降低输出。
- 不要让膜片自由端直接撞击金属或亚克力硬边。
- 不要在完成强度标定后改变悬臂长度、触摸点或泡棉厚度。
- 不要用手拿着 PVA103 的输入端或裸露传感器线演示，人体耦合会放大 50 Hz 干扰。

## 4. 抗干扰机械布置

1. PVA103 应放在传感器旁边，优先缩短传感器线。
2. Pico、USB 接头和电脑电源线应位于触摸区另一侧。
3. 传感器线必须与 USB 线交叉时，尽量接近 90°，不要长距离平行。
4. 如果必须使用屏蔽层，屏蔽层只在 PVA103 端接 GND，传感器端不接，避免地环路。
5. 电路板下方使用绝缘隔离柱，不能直接放在导电桌面或铝板上。

## 5. PVA103 增益调整

PVA103 板上电位器可把灵敏度调整到约 1–100 倍。按厂商说明，从元件面观察，顺时针增大，逆时针减小。

PVA103 在 3.3 V 供电时的有效输出摆幅并不能真正达到 0 V 和 3.3 V；按厂商资料估算，前端接近约 0.7 V 或 2.6 V 时已经可能削顶。因此本项目把约 0.75 V 和 2.55 V 作为接近前端饱和的警戒值，而不是等到 ADC 原始值达到 0 或 4095。

### 5.1 初始位置

1. 拔掉 USB。
2. 用小螺丝刀把电位器逆时针调到最低灵敏度附近；到达机械限位后立即停止用力。
3. 检查触摸片、传感器插头和公共地。
4. 插入 USB，等待上位机完成 2 秒基线测量。

### 5.2 调整步骤

1. 在固定触摸点做 5 次课程中预计最重的触摸。
2. 观察波形是否出现平顶、平底或连续相同的极值，并检查界面的“低轨/高轨/削顶”提示。
3. 若峰值很小且没有削顶，把电位器顺时针小幅转动，重新执行基线测量后再做 5 次重触。
4. 逐步增加，直到轻触能稳定越过事件阈值，同时 10 次最重触均不出现前端削顶。
5. 完成后做 5 次轻触和 5 次重触标定，不要用增加增益代替强度标定。

推荐把正常重触的变化电压峰值调整到约 0.35–0.70 V。这个范围是课堂教具的起点，不是传感器规格；最终标准仍是轻触可识别、重触不削顶、静置无误触。

不要机械套用“重触达到 ADC 总量程 70%–80%”作为单一目标。PVA103 输出带直流偏置，按下和释放还可能向两个方向摆动；只追求某个绝对 ADC 数字，可能让另一方向先撞到约 0.7 V 或 2.6 V 的前端边界。本教具以“正负动态峰值都留在有效摆幅内、10 次最大正常触摸均不触发近轨标志”为最终判据。

### 5.3 如何判断增益过低

- 轻触峰值与静置噪声接近，事件经常漏检；
- 五次相似轻触中只有少数能够触发；
- 提高软件强度映射后仍然看不到清晰波形。

### 5.4 如何判断增益过高

- 波形顶部或底部形成明显平台；
- 固件 `flags.bit0` 或 `flags.bit1` 经常出现；
- 轻触已经接近 100%，轻、中、重无法拉开；
- 静置时工频干扰不断触发事件。

降低阈值不能补救增益过低，降低软件强度上限也不能补救模拟前端削顶。应先把硬件增益调整到有信噪比且有余量，再进行软件标定。

## 6. 更改结构后的处理

发生以下任一变化时，必须重新执行基线和轻/重触标定：

- 转动 PVA103 电位器；
- 更换 LDT0-028K 或 PVA103；
- 改变触摸片材料、悬臂长度、泡棉或触摸位置；
- 重新粘贴传感器；
- 把装置搬到噪声环境明显不同的位置。

如果只是重新插拔 USB，机械结构和增益没有变化，仍建议做 2 秒基线测量，但不一定需要重做轻/重触标定。
