# LDT0-028K 触摸数据教具文档

本目录说明如何把 LDT0-028K 压电膜、PVA103 电荷放大模块和 Raspberry Pi Pico 组装成一套可在电脑上显示波形、识别动态触摸并把事件发送给机器人模拟器的教具。

## 先说明一个容易误解的边界

LDT0-028K 是压电膜传感器。它擅长感知触碰、敲击、弯曲和压力变化速度，但不能像称重传感器一样持续测量静态压力。手指按住不动后，波形回到基线是正常物理现象，不是程序丢数据。

本教具默认展示以下量：

- ADC 原始值；
- PVA103 输出端电压；
- 相对基线的变化电压；
- 0–100 的动态触摸强度和轻、中、重分类；
- 触摸事件、串口帧、机器人 JSON 和确认回执。

没有与参考测力计进行同结构、同速度的动态标定时，不得把相对强度改名为“压力 N”。如果课程目标是测量手指按住期间的持续力，应增加 FSR 或称重传感器，而不是通过软件伪造静态压力。

## 推荐系统结构

```text
LDT0-028K
    │ 动态形变产生电荷
    ▼
PVA103 电荷放大模块
    │ OUT 模拟电压
    ▼
2.2 kΩ + 100 nF 低通/隔离网络
    │
    ▼
Raspberry Pi Pico GP26/ADC0，2 kS/s
    │ USB CDC，20 点/10 ms 一帧
    ▼
电脑上位机
    ├─ 实时波形、动态强度、事件、记录
    └─ TCP NDJSON → 机器人模拟器/机器人适配器
```

## 统一默认值

| 项目 | 默认值 |
| --- | --- |
| MCU | Raspberry Pi Pico，RP2040 |
| ADC | GP26 / ADC0，Pico 物理 31 脚 |
| 参考电压 | 3.3 V |
| 采样率 | 2,000 sample/s |
| 批大小 | 20 点 |
| 批周期 | 10 ms |
| 电脑连接 | USB 原生 CDC；界面中的 115200 仅为兼容占位 |
| 机器人连接 | TCP NDJSON，默认 `127.0.0.1:18080` |
| 机器人遥测 | 20 Hz |
| 机器人事件 | `event_start`、`event_end` 立即发送并等待 ACK |

## 安全底线

- 整套电路只使用 Pico USB 和 3.3 V 供电，不接市电。
- PVA103 必须由 Pico 的 `3V3(OUT)` 供电，不能接 `VBUS` 5 V。
- 接线、插拔传感器和调整机械结构前先拔掉 USB。
- 首次联调先使用本机机器人模拟器；真实机器人默认禁止运动输出。
- 真实机器人只允许调用预先批准的动作，必须保留急停和人工使能。
